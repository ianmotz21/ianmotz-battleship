# Battleship

A starter Next.js (App Router) + TypeScript project for a Battleship game. No game logic yet — just the homepage with two empty 10x10 boards.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

- `src/app/page.tsx` — homepage
- `src/components/Board.tsx` — reusable 10x10 board placeholder

## Scripts

- `npm run dev` — start dev server
- `npm run build` — production build
- `npm run lint` — run ESLint
